Understanding

Project Overview

What Problem It Solves

SMKN 9 Kabupaten Tangerang lacked a centralized digital presence for sharing announcements, academic information, and school activities. Important updates were scattered across social media and word-of-mouth, leading to missed information.

Prospective students and parents had no easy way to learn about programs, facilities, and achievements. The school needed a professional digital identity to reflect its quality of education and TJKT program excellence.

Why It Was Built

As a TJKT student, I wanted to contribute to my school community while applying my web development skills. This project serves as both a practical learning experience and a lasting digital asset for the institution.

Main Objectives

Create a responsive information portal with news management, program showcases, faculty profiles, contact integration, and an admin panel for content updates without coding knowledge.

Target Users

Current students, prospective students, parents, faculty members, school administrators, and the local community seeking information about SMKN 9.

Key Innovation

A lightweight CMS built from scratch using PHP and MySQL, allowing non-technical staff to update content through a simple admin interface without touching code.

Process

How It Works

From planning to a live school portal.

Content Planning

Identified all necessary sections: homepage, about, programs, news, faculty, gallery, and contact. Created a content hierarchy and information architecture.

Design

UI Design

Designed wireframes and high-fidelity mockups in Figma. Focused on clean, modern aesthetics that appeal to students while maintaining institutional professionalism.

Frontend Development

Built responsive HTML/CSS layouts with semantic markup. Implemented JavaScript for interactive components, sliders, and mobile navigation with smooth animations.

Backend

Backend Integration

Developed PHP backend with MySQL database. Built authentication system, content management endpoints, and dynamic page rendering based on database content.

Testing

Cross-browser testing on Chrome, Firefox, Safari, and Edge. Mobile responsiveness verified on multiple screen sizes. Performance optimized for rural internet connections.

Deployment

Deployed to shared hosting with domain configuration. Set up SSL certificate, configured backups, and trained school staff on using the admin dashboard for content updates.
